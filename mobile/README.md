# Apps Responder Já (iPhone e Android)

Pasta reservada para as apps móveis, feitas com Expo (React Native). Decisão e plano: `docs/APPS.md`.

Esta pasta é independente do site:
- não entra na compilação nem nos erros de tipos do site (`tsconfig.json` → `exclude`);
- não é enviada para a Vercel (`.vercelignore`);
- terá o próprio `package.json` e as próprias dependências (RJ-11.2).
